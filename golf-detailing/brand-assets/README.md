# Brand Assets — Caddy 19

Draft, editable vector files (SVG = infinite scale, no designer needed). Open
`preview.html` to see them all together.

## Files

| File | Use |
|------|-----|
| `logo-primary.svg` | Horizontal lockup — website header, proposals, email signature, invoices. |
| `logo-icon.svg` | Circular emblem — polo shirts, favicon, social avatar, small spaces. |
| `bag-drop-card.svg` | 4×6 in member sign-up card for the bag drop / pro shop counter. |
| `car-magnet.svg` | 24×12 in vehicle door magnet for the rig. |
| `preview.html` | Contact sheet of all assets. |

## Palette

| Role | Hex | Notes |

## Type

- **Wordmark / headings:** Georgia (serif) — a stand-in for a premium serif. If you ever
  want a distinct custom wordmark, upgrade to a licensed face (e.g. Playfair Display,
  Canela) later; Georgia keeps us at $0 now and looks sharp.
- **Body / labels:** Helvetica Neue / Arial (system sans).
- Both are system-safe, so nothing to license or install.

## To use them

- **View/convert:** open any `.svg` in a browser; export to PNG/PDF for print via a free
  tool (e.g. the browser print-to-PDF, or a free SVG→PNG site) at the size noted.
- **Placeholders to swap before printing:** `[phone]`, `[website]`, `[ QR: book ]`, and
  the magnet's sample number — I'll drop in the real ones once the phone line + booking
  link exist.
- **Printing (low-cost):** bag-drop cards and magnets both print cheaply at
  Vistaprint/Signs.com/local shops. Order magnets only after the phone/URL are final.
